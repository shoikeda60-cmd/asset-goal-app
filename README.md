# 100万円まであと何日？ Webアプリ

## 使い方
1. このフォルダを GitHub Pages / Cloudflare Pages / Netlify などに公開
2. Android の Chrome で公開URLを開く
3. ブラウザメニューから「ホーム画面に追加」または「アプリをインストール」
4. 資産評価額を入力して「記録して更新」

## 初期設定
- 開始資産: 100,000円
- 目標資産: 1,000,000円
- 日次利益率: 0.5%
- 基準建玉: 10,000通貨
- 基準資産: 100,000円

## 保存
履歴・設定はブラウザの localStorage に保存されます。同じ端末・同じブラウザで使う限り保持されます。
